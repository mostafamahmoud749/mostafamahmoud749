## Projects

**Zamazon** is an Amazon-inspired shopping app I built where you can browse products, save items to your cart, place orders, and leave reviews. I built the storefront with Next.js and the order API with Express and PostgreSQL. If your connection drops during checkout, retrying the same request brings back your original order and leaves any new items in your cart. [Live demo](https://zamazon-chi.vercel.app/) · [Source code](https://github.com/mostafamahmoud749/Zamazon)
